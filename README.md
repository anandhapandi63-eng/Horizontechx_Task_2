# Stock_Portfolio_Tracker

## Overview

The Stock Portfolio Tracker is a console-based Python application that helps users calculate the total value of their stock investments. Users enter stock symbols and quantities, and the program uses predefined stock prices to calculate the overall portfolio value.

## Features

* User-friendly console interface
* Predefined stock price dictionary
* Calculates individual investment values
* Displays total portfolio value
* Option to save the portfolio report to a text file

## Technologies Used

* Python 3

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python stock_portfolio_tracker.py
```
